# Estante

App para catalogar os livros de uma biblioteca: foto da capa, leitura do código de barras (ISBN) ou busca por título e autor.
Organiza por assunto, por seção (nomes que você cria, como "Prateleira 1" ou "Lado 2") e em ordem alfabética de autor ou título.

Abra pelo link do GitHub Pages no celular e use "Adicionar à tela inicial" para instalar.
Os dados ficam guardados no próprio aparelho. Use Ajustes > Exportar backup de vez em quando.
